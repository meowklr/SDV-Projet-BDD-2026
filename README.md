# Morghul's Chronicles (V2)

Jeu de combat au tour par tour en ligne de commande, développé en Python avec stockage des données dans MongoDB (migration SQL prévue), dans le cadre d'un projet d'études en 2ème année.

## Installation & lancement

```bash
pip install -r requirements.txt
python -m db.db_init
python main.py
```

## Démo des vues (sans MongoDB)

```bash
python demo_views.py
```
